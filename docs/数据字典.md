# EduLab 交互教学课件平台 — 数据字典

| 项 | 内容 |
|----|------|
| 文档版本 | v1.2 |
| 存储模式 | MySQL 或 Memory JSON（字段语义一致） |
| 字符集 | utf8mb4 |

---

## 1. 总览

| 实体/表 | 中文名 | 说明 |
|---------|--------|------|
| users | 用户 | 账号与角色 |
| sessions | 会话 | 登录 Token |
| generation_jobs | 生成任务 | 固定题型与 AI 任务 |
| lessons | 课件 | 生成结果元数据 |
| lesson_assets | 课件资产 | HTML 等文件索引 |
| problem_catalog | 题型目录 | 固定题启停 |
| system_config | 系统配置 | KV 配置 |
| ai_daily_quota | AI 日配额 | 用户每日计数 |
| ai_image_drafts | 图片识别草稿 | 确认前门闩 |
| molecule-extensions.json | 分子扩展库 | 文件型扩展数据（非 SQL 表） |

Memory 模式下还包含聚合根文件字段：`users/sessions/jobs/lessons/assets/catalog/aiQuota/aiImageDrafts/config`。

## 2. users（用户）

| 字段 | 类型 | 空 | 默认 | 说明 |
|------|------|----|------|------|
| id | VARCHAR(64) PK | N | 生成 `usr_` | 用户 ID |
| email | VARCHAR(255) UNIQUE | N | | 登录邮箱（小写） |
| nickname | VARCHAR(128) | N | | 昵称 |
| password_hash | VARCHAR(255) | N | | 密码哈希 |
| role | VARCHAR(32) | N | student | student/teacher/admin |
| status | VARCHAR(32) | N | active | active/disabled 等 |
| created_at | TIMESTAMP | N | now | 创建时间 |

**取值约束**

- role ∈ {`student`,`teacher`,`admin`}
- status 常用 `active`

## 4. generation_jobs（生成任务）

### 4.1 基础字段

| 字段 | 类型 | 空 | 默认 | 说明 |
|------|------|----|------|------|
| id | VARCHAR(64) PK | N | `job_` | 任务 ID |
| user_id | VARCHAR(64) | N | | 发起用户 |
| status | VARCHAR(32) | N | queued | 见状态枚举 |
| progress | INT | N | 0 | 0–100 |
| current_stage | VARCHAR(255) | Y | '' | 阶段；AI 使用 `routing/generating_spec/validating/repairing/extending_molecules/rendering/persisting` |
| skill_id | VARCHAR(64) | N | | 技能 ID，可空串（AI 待路由） |
| problem_type | VARCHAR(64) | N | | 题型 key 或 ai_dynamic |
| params | JSON | Y | | 固定参数/AI options |
| title | VARCHAR(512) | Y | '' | 标题 |
| error_message | TEXT | Y | | 失败信息 |
| result_lesson_id | VARCHAR(64) | Y | | 成功课件 ID |
| worker_token | VARCHAR(128) | Y | | 租约令牌 |
| lease_until | DATETIME | Y | | 租约到期 |
| created_at | TIMESTAMP | N | now | |
| updated_at | TIMESTAMP | N | now | |

### 4.2 AI 扩展字段

| 字段 | 类型 | 空 | 默认 | 说明 |
|------|------|----|------|------|
| kind | VARCHAR(16) | N | fixed | `fixed` / `ai` |
| input_mode | VARCHAR(32) | N | catalog | catalog/text/equation/image |
| source_text | MEDIUMTEXT | Y | | AI 输入文本 |
| source_asset_id | VARCHAR(64) | Y | | 源图片资源 ID 或已落盘路径 |
| draft_id | VARCHAR(64) | Y | | 关联图片草稿 |
| skill_hint | VARCHAR(64) | Y | | 用户/系统学科提示 |
| idempotency_key | VARCHAR(128) | Y | | 幂等键 |
| error_code | VARCHAR(64) | Y | | 机器可读错误码 |
| spec | JSON | Y | | 最终/中间 Spec |
| validation_trace | JSON | Y | | 校验/重试轨迹 |
| molecule_extensions | JSON | Y | | 本次新增分子列表 |
| ai_meta | JSON | Y | | 模型/路由/usage 等 |

**索引**

- `idx_jobs_user(user_id)`
- `idx_jobs_status(status)`
- `uq_jobs_idempotency(user_id, idempotency_key)`（唯一；NULL 幂等键不参与去重）

### 4.3 枚举

**status**

| 值 | 含义 |
|----|------|
| queued | 排队 |
| running | 执行中 |
| succeeded | 成功 |
| failed | 失败 |
| cancelled | 取消 |

**kind**

| 值 | 含义 |
|----|------|
| fixed | 目录固定题型 |
| ai | AI 动态生成 |

**input_mode**

| 值 | 含义 |
|----|------|
| catalog | 固定目录 |
| text | 文本 |
| equation | 方程/式子 |
| image | 图片确认后 |

### 4.4 JSON 结构约定

#### params（示例）

```json
{
  "options": { "title": "自定义标题" },
  "editable": { "problemText": "...", "equation": "..." },
  "fromDraftId": "draft_xxx"
}
```

#### validation_trace（数组元素示例）

```json
{
  "attempt": 1,
  "phase": "validate|llm|extend_molecules",
  "ok": false,
  "error": "...",
  "code": "UPSTREAM_HTTP",
  "summary": {}
}
```

#### ai_meta（示例）

```json
{
  "provider": "sub2api",
  "pipeline": "m2_chem|m3_analytic|m4_image",
  "route": "known_registry|llm_spec",
  "knownKey": "electrolysis_water",
  "requestedAt": "ISO-8601",
  "attempts": [
    { "attempt": 1, "model": "deepseek-v4-flash", "usage": {}, "finishReason": "stop" }
  ],
  "moleculeExtended": ["S", "SO2"],
  "fromDraft": true
}
```

#### molecule_extensions（数组元素）

与分子库条目相同，见第 11 节。

#### spec

- 化学：reaction morph spec 或 `{route,key,sourceText}`
- 解几：`{lesson,steps,board}`

## 11. 分子扩展库（文件）

路径：`MOLECULE_EXTENSIONS_FILE` 或默认 `server/data/molecule-extensions.json`

### 根对象

| 字段 | 类型 | 说明 |
|------|------|------|
| version | number | 结构版本，当前 1 |
| molecules | array | 分子定义列表 |
| updatedAt | string | ISO 时间 |

### molecules[] 元素

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| id | string | 是 | 物种 ID，如 SO2 |
| formula | string | 建议 | 显示式 |
| latex | string | 建议 | LaTeX |
| name | string | 建议 | 中文名 |
| name_en | string | 建议 | 英文名 |
| color | string | 否 | 主题色 token |
| atoms | array | 是 | 原子列表 |
| bonds | array | 是 | 键列表（可为 []） |
| status | string | 否 | active/disabled |
| source | string | 否 | llm/manual |
| createdAt/updatedAt | string | 否 | 时间 |

#### atoms[]

| 字段 | 类型 | 说明 |
|------|------|------|
| slot | string | 分子内唯一槽位 |
| el | string | 元素：H,C,N,O,S,Cl,Na,Fe,Cu,Mg |
| pos | number[3] | 局部坐标 |

#### bonds[]

| 字段 | 类型 | 说明 |
|------|------|------|
| a | string | slot |
| b | string | slot |
| order | 1\|2\|3\|"ionic" | 键级 |

## 13. 化学 Spec 数据字典（AI）

根对象常用字段：

| 字段 | 类型 | 说明 |
|------|------|------|
| meta | object | title/subtitle/language/category/accent/engine |

## 18. 数据保留与清理建议

| 数据 | 建议 |
|------|------|
| sessions | 按 TTL 清理 |
| failed jobs | 保留便于审计，可定期归档 |
| drafts | expires_at 后标记 expired 并可删 |
| lesson HTML | 随 lesson 删除级联清理文件 |
| molecule extensions | 长期保留；disabled 软删 |
